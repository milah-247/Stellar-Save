# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report privately to: **security@stellar-save.example**
HackerOne: **https://hackerone.com/stellar-save**

See [security/BUG_BOUNTY.md](security/BUG_BOUNTY.md) for full programme details, reward tiers, and the response timeline.
